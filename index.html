Riftdle

Built and operated solo. Live at riftdle.lol since March 2026. Source is private.

  • React 19
  • Vite

  • Python

A daily guessing game for a trading card game, grown organically to 11,000 players and still climbing. Six modes, 26 achievements, and streaks that survive across devices. I built the game engine, the data pipeline, the analytics platform, the CDN and the test suite.

How each figure was set

14.6GB/day

Cut hosting cost to zero

Firebase Hosting was serving 14.6 GB of card art every day. I moved every asset to Cloudflare R2 behind a custom CDN domain and bandwidth spend went to nothing overnight.

1,100cards

Automated the data pipeline

A Python scraper pulls card data, artwork and keywords straight from Riot's official gallery into JSON5. Onboarding a new set is a script run, not a week of typing.

13pages

Built the analytics myself

A React dashboard tracks retention cohorts, guess distributions, device mix and player geography. When traffic pushed Firebase past its free download quota I moved it onto an IndexedDB cache with delta fetches instead of pulling the whole database on every open.

31e2e tests

Kept it from breaking

Playwright tests cover all six modes, streaks and cross device sync so regressions are caught before deploy. Server side Firebase rules validate every write: increment only, one submission per player per day.

Since launch Connections, a card grouping puzzle with a community submitted archive. Endless mode with monthly and all time leaderboards. A fourth card set onboarded, a scheduled job that protects streaks while players are away, and a monthly community recap.

02Live tool

Blood on the Clocktower Token Mapper

  • JavaScript
  • Cloudflare Pages
  • Cloudflare D1

A free tool that turns any custom script into printable token sheets, so groups stop hand writing substitutes before every game.

The base box ships around 20 characters, but almost nobody plays those. Groups pull a custom script off the community site, then either buy more tokens or scribble replacements on blanks.

Paste in a script and the mapper works out which spare token can stand in for each missing character, then prints ready to cut player sheets and a storyteller night order sheet built around that substitution.

One self contained HTML file with no dependencies, behind a Content Security Policy that pins the hash of its single inline script, so nothing else can execute on the page. Print activity goes to Cloudflare D1 anonymously, counts and country only.

03Ongoing

AI Music Videos

  • ComfyUI
  • Flux
  • WAN
  • DaVinci Resolve

Full music videos made with generative AI instead of a camera and a cast, published as Yulia Labels.

Character stills come out of Flux, then get animated with WAN image to video. Chaining the last frame of one clip into the start of the next keeps the camera moving continuously across a shot instead of resetting every few seconds, which is the part most AI video gets wrong.

Vocals are lip synced to the real track, then everything is upscaled and colour matched before the final cut in Resolve.

04Community

Pixelborn Card Scraper

  • Python
  • Selenium
  • Requests

When 1,000+ players lost access to the card art overnight, I scraped and republished the whole set. It has since passed 8,000 views and became the link the community shares.

A community built digital version of the game made players download copyrighted card art themselves. The person hosting the main link went on holiday and took it with them.

I pulled the art and icons from official sources, sorted them by rarity using colour recognition, resized everything to the dimensions the client expects, and put the set on archive.org where it could not disappear again.

Weather informed traffic forecasting

Honours dissertation testing whether weather data makes traffic flow prediction meaningfully better.
