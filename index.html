01

Riftdle

Live since March 2026

A daily card game for a trading card community. I designed it, built it, and I run it alone.

More than 11,000 players, 100,000+ games and 5,900+ hours played. Six modes, 26 achievements and 1,100+ cards across four sets. The repository is private.

Decisions with a cost
14.6 GB a dayCard art was the hosting bill. Moving delivery to Cloudflare R2 behind a custom domain took the bandwidth cost with it.
1,100+ cardsA Python pipeline pulls card data, art and keywords from the official gallery. Adding a set is a script run, not manual entry.
13 viewsThe analytics dashboard covers cohorts, guesses, devices and geography. A browser cache and delta fetches keep reads inside the free quota.
31 testsPlaywright covers all six modes, streaks and cross device sync. Server rules validate every score write.

React, Firebase, Python, Cloudflare R2

02

Rumpus

In build

Browser party games. Send a link, play in seconds, no apps and no accounts.

Eleven games share one room and one set of rules, held between the browser and a room server. The worlds are 3D and run in a browser tab.

What is in the room
11 gamesHue Off, Two Thirds, Gridlock, Beamline, Fuse, Spectrum, Lowest Unique, Flock, Acre, Lantern and Pong, each with its own world and twists.
12 seatsOne room, twelve players. Rules and positions live between the browser and the room server rather than trusting either.
3D in a tabReact Three Fiber over Three.js, with scenes kept apart from clock updates and pixel ratio capped so phones keep up.
2 lanesPlaywright covers the room flow end to end, and every release goes to staging before production.

Next.js 16, React Three Fiber, Cloudflare Workers, partyserver

03

BotC Token Mapper

Live

Turns a custom Blood on the Clocktower script into printable token sheets. Community groups were doing this by hand.

Paste in a script and it pairs every missing character with a spare token, then builds the player sheets and a storyteller night order sheet.

How it ships
1 fileA single dependency free HTML page, served behind a strict Content Security Policy with a hash pinned per page.
181 charactersCharacter data and art come from the official release, so a new script works the day it is written.

JavaScript, Cloudflare Pages, D1
